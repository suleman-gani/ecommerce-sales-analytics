📊 E-Commerce Sales Analytics Dashboard

An interactive Microsoft Excel dashboard designed to analyze e-commerce sales performance, product categories, customer orders, and regional sales.

🎯 Project Overview

This project focuses on analyzing e-commerce sales data to identify sales trends, top-performing products, and regional performance using Microsoft Excel.
### 📸 Dashboard Preview

![E-Commerce Sales Analytics Dashboard](ecommerce%20Dashboard.png)


🛠️ Tools & Technologies

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Data Analysis
- Data Visualization

📈 Dashboard Features

- Sales KPIs: Total Sales, Total Orders, and Average Sales.
- Category Analysis: Revenue comparison across product categories.
- Regional Analysis: Sales performance across states and cities.
- Product Analysis: Top 5 products by revenue.
- Sales Trends: Sales and order trends over time.
- Interactive Filters: Filter dashboard data by category and state.

- 🔍 Key Insights

- Total Revenue: Generated ₹30.03 lakh in sales across 82 orders.
- Top Category: Furniture contributed the highest revenue (₹10.48 lakh), followed by Technology (₹10.26 lakh).
- Top City: Gurgaon recorded the highest sales at approximately ₹1.79 lakh.
- Top Product: Office Chair generated the highest product revenue of ₹2.20 lakh.
- Sales Trend: January recorded ₹15.83 lakh in sales, while February recorded ₹14.15 lakh.
